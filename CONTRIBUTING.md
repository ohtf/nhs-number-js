# Contributing

Install with `npm ci --ignore-scripts` and run `s/test` before submitting a change. For intended behaviour changes, read the [validation contract](spec/standard.md) and coordinate changes to the shared fixture with the Python project. Keep real patient identifiers out of every contribution.

Use conventional commits and add a Developer Certificate of Origin sign-off with `git commit -s`. Once a remote exists, target `main` with a focused pull request. See the [house style](https://github.com/pacharanero/house-style/blob/main/AGENTS.md).
